Hackathon Submission Specifications

Complete compliance documentation addressing every requirement of the prompt.

1. At Least 1,000 Company Profiles

Generated via asynchronous high-throughput harvesting against official Brønnøysundregistrene APIs. Available in four formats:

  • data/profiles_1000.json: Full structured JSON array.
  • data/profiles_1000.jsonl: Line-delimited stream format.
  • data/profiles_1000_summary.csv: Tabular metrics overview.
  • data/company_profiles.db: Indexed SQLite database.

2. Permitted Public Sources Monitored

  • Enhetsregisteret (The Register of Legal Entities): Open REST API (NLOD 2.0).
  • Roller i Enhetsregisteret: Corporate governance, CEO, board chair, auditor.
  • Regnskapsregisteret: Audited annual financial statements and key figures.
  • Oppdateringer Stream: Live delta feed to keep profiles current.
  • Official Domains: Public web footprints grounded with entity match check.

3. Fact Disambiguation & Entity Resolution

Solves "Make sure each fact belongs to the right company":

  • Primary Key Invariance: Enforces strict organisasjonsnummer matching across all registry endpoints.
  • Modulo 11 Checksum: Discards mathematically invalid org numbers before querying.
  • Name & Alias Alignment: Levenshtein/token matching across official legal names and historical aliases (historiskeNavn).
  • Provenance Ledger: Every fact contains source URL, publication date, and verification score.

4. Keeping Profiles Current

Solves "keep profiles current":

  • Tracks the official Brreg oppdateringer/enheter stream.
  • Compares the company's latest recorded update event ID against the registry's current stream head.
  • Automatically identifies modified companies (NEEDS_SYNC) and updates changed fields while retaining change logs.

5. One Command to Run It

python run.py --orgnr 923609016

Or launch the interactive web dashboard:

python run.py --serve

  • Base Data Cost: $0.00 (Brønnøysundregistrene is 100% free under NLOD 2.0).
  • AI Inference: Gemini 2.0 Flash (~$0.0001 per profile summary, or $0.00 in deterministic mode).
  • Total Cost for 1,000 Profiles: $0.00 to <$0.10.
