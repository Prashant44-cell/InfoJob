Modulo-11 Mathematical Specification
Weights: [3, 2, 7, 6, 5, 4, 3, 2]
Formula:
  Sum = Σ (digit[i] * weight[i]) for i in 0..7
  Remainder = Sum % 11
  If Remainder == 0: control = 0
  If Remainder == 1: INVALID (Norwegian standard rejects remainder 1)
  Else: control = 11 - Remainder
  Valid iff digit[8] == control

InfoJob / SignalPost Architecture & Specifications

1. Project Mission & Identity

Autonomous Norwegian Corporate Intelligence Studio designed to query, disambiguate, verify, and maintain 1,000+ Norwegian enterprise dossiers with 100% Modulo-11 mathematical accuracy and official Brønnøysund provenance.

2. Pipeline & Sources

Integrates permitted open government sources: Enhetsregisteret (entities), Roller & Styre (governance), Regnskapsregisteret (audited accounts), and Oppdateringer (delta update stream), plus Apify real-time actor crawlers.

3. Modulo-11 Checksum Verification

Every Norwegian organization number is strictly validated against weights [3, 2, 7, 6, 5, 4, 3, 2] ensuring zero corrupted or hallucinated organization records enter the database.

4. Single Command Execution

Full backend and frontend dashboard launched via: python run.py --serve on http://127.0.0.1:8000.
