# Novel Design Synthesis & Anti-Cloning Rule

When building or styling web user interfaces:
1. **Never Clone Reference Layouts Verbatim**: When provided with design references, mockups, or screenshots, treat them as thematic inspiration and functional context—never replicate the layout, color scheme, or card structure one-to-one.
2. **Mandate Novel Architectural Patterns**:
   - Employ modern layout patterns such as **Bento Grid architecture** with asymmetric spans (`col-span-2`, `row-span-2`, `col-span-5`), focal metric modules, and clear visual hierarchy.
   - Utilize spatial depth, subtle glassmorphism (`backdrop-filter: blur()`), soft layered elevation shadows, and discrete micro-animations.
3. **Elevate Domain-Specific Visuals**:
   - Create bespoke domain visualizers (e.g., live algorithmic checksum step-tracers, telemetry stream inspectors, and interactive data radars) instead of static tables or plain text fields.
4. **Professional Iconography & Typography**:
   - Use high-quality vector SVG icons exclusively (never emojis for UI controls or navigation badges).
   - Use curated font pairings (e.g., Plus Jakarta Sans + Inter + JetBrains Mono) with strict contrast ratios (minimum 4.5:1).
